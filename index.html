Как пользоваться Открыть Sketch Engine

Инструкция по работе со Sketch Engine

  1. Откройте Sketch Engine по кнопке выше и войдите в аккаунт. Для работы нужно выбрать готовый англоязычный корпус, British National Corpus.
  2. Для значения слова по контексту используйте Concordance: введите слово, изучите строки KWIC и сравните разные контексты употребления.
  3. Для коллокаций используйте Word Sketch: введите ключевое слово и посмотрите типичные сочетания, сгруппированные по грамматическим отношениям.
  4. Для частотных слов используйте Word List: задайте тему/корпус и отсортируйте результаты по частотности.
  5. Записывайте доказательство: 1-2 примера из корпуса, частотность или типичное сочетание. Это поможет объяснить ответ, а не просто угадать его.
